# 工程骨架与工具链基线

状态：accepted（2026-10-29）

票 05 落地前后端骨架时定下的、之后回头改代价明显的一组基线。写在这里是因为「为什么是这样」在代码里看不出来。

## 坐标与布局

- 后端根包 `com.travelshare`，artifact `travel-share-backend`，Spring Boot **2.7.18**（方案 §6.1 的 2.7.x 线，取该线最后一个版本）；JDK 17。
- 仓库根下 `backend/` 与 `frontend/` **平级**。前端**不**塞进 `backend/src/main/resources/static`：那会让 Vite dev server 与代理冒烟一起失效，只能在打包期用。
- 后端**不设** `server.servlet.context-path`；`/api` 前缀由各控制器显式写（`@RequestMapping("/api")`）。这样 HLD §2.2 的接口前缀表与代码一一对应，代理侧不需要 `rewrite` 抹前缀。

## 骨架的边界（故意没做的事）

- 只有 `GET /api/ping` 一个接口，**没有** 8 个业务包、**没有** JwtInterceptor、**没有**全局异常处理器。骨架只证「HTTP + 代理 + 统一响应信封」一条链路，其余留给实施票。
- 数据源已配（`127.0.0.1:3307/travel_share`，caching_sha2 需 connector-j 8.x），但**启动不验库**、ping 不碰数据源。理由：`travel_share` 当下 0 张表，把库健康度塞进骨架验收会让冒烟被 MySQL 状态绑架。
- 因此「启动即连库失败」不会在这里暴露；实施票接入 mapper 后要单独验一次连通性。

## 包管理器：pnpm（不用 npm）

前端锁文件只留 `pnpm-lock.yaml`。
考虑过 npm（两者都实测可用，DEV-ENVIRONMENT 有记录）。选 pnpm 是因为 store 内容寻址 + 硬链接（`F:\.pnpm-store\v11`）：47 个包 2.2s 装完，票 03 实测 npm 18.5s / pnpm 4.8s；Element Plus 全家桶进场后差距只会更大。代价是需要额外装 pnpm —— 单人毕设不构成问题。

## 两个环境坑的处置边界

- **`JAVA_HOME`**：机器级已是 `F:\dev-tools\jdk17`，但已开着的 shell / IDE 仍持有旧值 `E:\space\09-tools\Jdk1.8`，此时 `mvnw` 报 `1.8.0_144`。**不改任何系统环境变量**（DEV-ENVIRONMENT 记「未授权改动、仅记录」）；构建/运行前在会话内 `export JAVA_HOME=/f/dev-tools/jdk17`。
- **Maven 镜像**：`~/.m2/settings.xml` 把 central 镜到 `maven.aliyun.com/repository/public`，**该 URL 直接访问实测 404**，但实际依赖下拉全部成功（1 分钟拉完 Spring Boot 全家桶）。记录不改；若将来真的拉不动，兜底用 `https://repo1.maven.org/maven2/`（实测 200）或 `https://repo.huaweicloud.com/repository/maven/`。
- **pnpm 构建脚本**：pnpm 12 默认拦 install-scripts，首次装报 `ERR_PNPM_IGNORED_BUILDS`（esbuild）。放行写在 `frontend/pnpm-workspace.yaml` 的 `allowBuilds.esbuild: true`，可复现且进版本库；`pnpm approve-builds` 是交互式的，不适合复现。

## 冒烟判据（可复现）

1. `backend> export JAVA_HOME=/f/dev-tools/jdk17; mvnw.cmd -B -DskipTests package` → BUILD SUCCESS
2. 起 jar，`curl http://127.0.0.1:8080/api/ping` → `{"code":200,"message":"success",...}`
3. `frontend> pnpm dev`，`curl http://localhost:5173/api/ping` → **同一个 body**（必须用 `localhost`：Vite 5 默认只监听 `[::1]`，打 `127.0.0.1:5173` 会连不上）
