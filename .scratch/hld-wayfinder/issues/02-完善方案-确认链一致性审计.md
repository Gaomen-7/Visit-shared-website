# 02: 《完善方案》× 确认链一致性审计

Type: research

Status: resolved
## Question

《旅游攻略分享网站毕业设计完善方案.md》（确认链定案前的旧文，从未按定案回写）哪些表述与已确认文档链（FSR / SRS / GDD / hld.md）的定案冲突？

## 输入与范围

- 比对对象：方案文档 §一–§十一，重点 §六（技术架构）/ §七（数据库）/ §八（REST API）；基准 = 已确认的 FSR.md / SRS.md / gdd.md 与 hld.md v1.0（含其 §1.1 十项决策索引）
- 已实绪 5 处起步（2026-10-29 抽查）：①「Spring Security 或自定义拦截器」vs SRS §8 定案自定义拦截器+jjwt；②「本地磁盘或阿里云 OSS」vs FSR §4.1 定案本地磁盘；③ report 表「选做」vs hld.md §3.2 不建；④「攻略四状态流转」vs SRS §1.3 五态八条边；⑤ 核心表「10 张」vs hld.md §3.2 P0 九张
- 已知非冲突（勿报）：WangEditor（SRS FR-ART-01 已定案）；Knife4j（SRS NFR-07 硬性要求，缺口在 hld.md §2.2 未挂，归「HLD v1.0 定案项拷问与批复」票处理）

## 产出

冲突清单落 `.scratch/hld-wayfinder/`：每条含方案文档位置与原文、确认链定案与出处、裁决建议；作为 HLD 批复拷问的弹药。

## Answer

**结论**：方案文档 §一–§十一 共 **21 处需处置**（硬冲突 8 · 字段与库表缺口 4 · 范围标记 1 · 表述精度 8）+ 确认链内部不一致 2 处 + 方案自身内部矛盾 3 处。票面预置的 5 处全部复核命中，另新增 16 条。

**产出（唯一资产）**：[审计 · 冲突清单](../../audit-完善方案-确认链冲突清单.md) —— 每条四段：方案位置（行号 + 小节标题）/ 原文 / 确认链定案与出处（文件 + 行号）/ 裁决建议 + 理由。正文不复制任何确认链规则，只做定位与裁决建议。

**八条硬冲突（按严重度）**：
1. **DB06 逻辑删除被写成全域规则**（方案 §7.3 L196）——这是唯一能**直接写坏代码**的一条：给 like_record / collect_record 加 deleted，`user_id + article_id` 唯一索引防重立刻失效，FR-ACT-01/02 验收判据全废。定案见 hld §3.2 剪裁 2。
2. **DB01 认证选型二选一残留**（§6.1 L127 / §6.3 L159）——「Spring Security 或 自定义拦截器」vs SRS §8「自定义拦截器 + jjwt，不采用 Spring Security」。
3. **DB07 审核状态机排期错位**（§10.1 L253）——P0 的状态机被排进第 11–12 周 P1 时间盒，按方案排期第 10 周末 CP2 判据不成立，会连带推翻 FSR §6 的进度可行性结论。**这条同时收口了 map「Not yet specified」点名要对的「16 周进度安排对齐」：错在方案排期，不在 FSR。**
4. **DB04「攻略四状态」两处**——GLOSSARY 已把「四态」列为 Avoid 词。
5. **DB03「核心表清单（10 张）」+ report 选做** vs hld §3.2 P0 九张。
6. **DB05「攻略与评论均可点赞」**——FSR §7 唯一一条正面偏离声明；方案自身不可实现（like_record 无 target 区分）。
7. **DB02 图片存储 OSS 分支**——断网演示与 ¥0 基线都挂在这句上。
8. **DB08 人均花费 DECIMAL 或整型**——GDD 已定 0–999,999 整数。

**另四类**：GP01–GP04 字段缺口（user 缺 intro、article 缺 content_text、carousel.link 无「对象选择器」形态、comment.parent_id 标「选做」而非「建表即含」）；RG01 关注/举报/系统设置仍标「加分选做」（FSR 已声明移入 P2）；PR01–PR08 表述精度（收藏夹 / 错误约定 / CORS / §十一 未标 P1 / JWT 画进 Controller / 表单必选性 / 「分类」无表 / 看板口径）。

**弹药已就绪**：清单 §7 给票 01 留了 6 个待裁决问题（Q1 裁决方向 = 全部改方案，而非反向修订 hld；Q2 方案是否升版加文档头；Q3 LC01/LC02 修在哪批；Q4 字段缺口落方案还是落 hld；Q5 指针 vs 复制；Q6 RG01 优先级）。

**一处越界提醒（需人裁决）**：自检发现 N1（P1「猜你喜欢」的「最近浏览」无库表支撑）**不在本图终点之内**——map §Out of scope 已把 P1 裁决划到 CP2 闸门之后。故本会话**不为其毕业新票**，只在清单 §8 留证，并把 map「Not yet specified」该条的收口结论写清。

21 条冲突与缺口全部定位到出处并给出裁决建议；产出 .scratch/hld-wayfinder/audit-完善方案-确认链冲突清单.md，作为票 01 批复弹药；执行侧移交票 07。
